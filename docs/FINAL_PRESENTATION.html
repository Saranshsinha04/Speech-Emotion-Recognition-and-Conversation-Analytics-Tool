5. Stage C: Conversational Context & Hypothesis H2

  • No-Context ResNet: 51.62% UAR (Low-Agr: 47.92%).
  • HMM-Forward Control: 66.45% UAR (Low-Agr: 62.86% (+14.94 pp), SeqAcc 74.24%, JSD 0.0816).
  • BiLSTM: 37.48% ± 0.40%; Causal Transformer: 27.20%.
  • Key Finding: Context strongly resolves ambiguity via Markov transition priors, while unanchored neural sequence heads overfit small 240-dialog corpora.

6. Generative Augmentation, Latent Space & Calibration

Temperature scaling (T*=1.256) cuts ResNet+SpecAug ECE from 0.1378 to 0.0708; CVAE augmentation achieves 56.29% UAR and 0.0298 ECE.

7. Escalation Detection (E11) & Acoustic Robustness (E13)

  • D6 TransformerHead: Highest ranking (AUROC 0.8030, AUPRC 0.4004, delay +1.0 turn).
  • D4 CUSUM (Audio-Only): Highest Event F1 (0.5538, FA/track 0.365).
  • Telephony & Noise Limits: 20 dB SNR stays at 52.58%, but 8 kHz telephony drops to 35.85% and 10 dB drops to 29.29%.

8. Java / ONNX Production Parity, Fairness & Failure Analysis

  • Exact Parity Verified: Java AudioFeatures Log-Mel parity < 5e-3; Java ORT vs PyTorch parity < 1e-4 (2.78e-6 ResNet, 1.19e-6 Transformer).
  • Real-Time CPU Speed: End-to-end Java call analytics runs in 239–715 ms on 28–38 s calls (RTF = 0.0085–0.0242).
  • Subgroup Spread (E9): Female 56.79% vs Male 52.21%; Age 50+ 61.38% vs 35–49 47.07%; Race spread 3.51 pp.
  • Demo Failure Case: On sample_routine_neutral.wav, ResNet-SER got 5/5 customer turns right (NEU, HAP, NEU, NEU, NEU) and D6 stayed quiet (0.276), whereas collapsed 6-class ContextTransformer logits caused a false HMM escalation alert.
